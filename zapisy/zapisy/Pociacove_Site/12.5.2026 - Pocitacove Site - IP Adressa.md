# Síťová vrstva | L3

- IP = **Internet Protocol**
- Zajišťuje:
	- **globální** adresaci v rámci celého světa nebo 
	- lokální adresaci v rámci jedné LAN
- Datová jednotka: Packet
- používáme IP adresy IPv4 - 32bitů, pouzívá se IP maska


```
  ----                Packet                  ----
+------------+-------------------------------------+
|            |                                     |
+------------+-------------------------------------+
 Hlavička IP | Segment
```

---

## Formát IPv4:


|Binární:|11101010|1010111|10010111|10001011| 
|-|-|-|-|-|
|Decimální:|175.|18.|21.|232|

- Maximální velikost 32. bitů

---

## Maska:
|Binární:|11111111.|11111111.|11110000.|00000000|
|-|-|-|-|-|
|Decimální:|255.|255.|240.|0|
|CIDR:|/20|

- Slouží pro logické rozdělení sítě (podsítě)
- **Rozdělení:**
	+ **Pro síť** - kde na binární pozici je **1**
	+ **Pro zařízení** (klienty) kde na birání pozici je **0**
- Klienti na dané podsíti můžou komunikovat mezi sebou, ale nemůžou do jiných podsítí bez L3 prvku
- Maskou se také určí rozsah dostupných IP adres na podsíti
> CIDR je zmenšený formát, v tomhle kontextu "/20" že 20 prvních bitů je použito pro síť a zbytek 32-22=10 pro klienty
- **Masky se taky dělí do tříd**

<br>**Třídy masky**
|Třída|Maska|Účel|
|-|-|-|
|A|255.0.0.0|ISP, a velké společnosti|
|B|255.255.0.0|Velké sítě (společnosti a univerzity)|
|C|255.255.255.0|Malé sítě (menši společnosti, domácnost)|
|D|x|Používá se pro multicasting|
|E|x|0 dostupných klientů, experimentální|

> Třída D a E se používají jen zřídka

```

Pro všechny příklady počítáme s adresou IPv4: 192.168.0.0

255.255.0.0

- 255. = pro síť
- 255. = pro síť
- 0. = pro zařízení
- 0. = pro zařízení

Binární: 11111111.11111111.00000000.00000000

CIDR: /16 - znamená že 16 bitů je pro síť a zbytek pro klienty

Dostupné IP adresy:
192.168.0.1 - 192.168.255.254
- Zde vidíme že na třetí pozici u konečného rozsahuje je "255", třetí pozice masky je 0. Max hodnota - Hodnota masky = 255 - 0 = 255.

Tohle znamená že zařízení si může vzít: X.X.0.0 (kromě poslední adresy)
= X reprezentují sekce IPv4 které zařízení si nemůže vzít

---

255.255.255.0

- 255. = pro síť
- 255. = pro síť
- 255. = pro zsíť
- 0. = pro zařízení

Binární: 11111111.11111111.11111111.00000000

CIDR: /24

Dostupné IP adresy:
192.168.0.1 - 192.168.0.254
- Zde vidíme že na třetí pozici u konečného rozsahuje je "0", třetí pozice masky je 255. Max hodnota - Hodnota masky = 255 - 255 = 0.

Tohle znamená že zařízení si může vzít: X.X.X.0 (kromě poslední adresy)
= X reprezentují sekce IPv4 které zařízení si nemůže vzít

---

255.255.240.0
- tenhle typ masek, kde je na jakékoliv pozici jiné číslo než 0 a 255 může být zmatkující

- 255. = pro síť
- 255. = pro síť
- 240. = po převedení 240 do binární soustvavy dostaneme "11110000", to znamená že poslední čtyři bity jsou použitelné pro klienty
- 0. = pro zařízení

Binární: 11111111.11111111.11110000.00000000

CIDR: /20 - znamená že 20 bitů je pro síť a zbytek pro klienty

Dostupné IP adresy:
192.168.0.1 - 192.168.15.254
- Zde vidíme že na třetí pozici u konečného rozsahuje je "15", třetí pozice masky je 240. Max hodnota - Hodnota masky = 255 - 244 = 15.

Pokuď chceme určit masku, která nemá 255 nebo 0 na jakékoliv pozici, tak si stačí převést ten daný segment do binární soustavu. Proto pro získání dostupných IP adres je více jednodušší si převést masku do binární soustavy nebo počítat s CIDR.

- 255. = pro síť

CIDR: /22 - znamená že 22 bitů je pro síť a zbytek pro klienty

Dostupné IP adresy:
192.168.0.1 - 192.168.3.254
- Zde vidíme že na třetí pozici u konečného rozsahuje je "3", třetí pozice masky je 252. Max hodnota - Hodnota masky = 255 - 252 = 3.
```
